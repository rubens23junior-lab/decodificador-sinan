1. O que o programa faz

Os arquivos de notificação do SINAN guardam quase tudo em códigos. O sexo vem como F, M ou I, a raça/cor vem como um número de 1 a 9, o município vem como um código de seis dígitos e a idade vem num código de quatro dígitos que junta a unidade (horas, dias, meses ou anos) e o valor. Os nomes das colunas também são abreviados, como CS_SEXO e ID_MUNICIP.

O Decodificador troca cada código pelo texto do dicionário de dados oficial do agravo e entrega uma planilha do Excel pronta para ler. A figura abaixo mostra três notificações do arquivo fictício antes e depois.

Os dados não saem do seu computador. O programa funciona inteiro dentro do navegador, sem internet, e não envia nem guarda nada. A planilha gerada tem os mesmos dados pessoais do arquivo original e deve ser tratada conforme as regras do seu serviço.

Diferente das tabelas do TABNET, que já vêm agregadas e só permitem as combinações de variáveis que oferecem, o arquivo do DATASUS tem uma linha por notificação, com todos os campos da ficha. Com a planilha legível, dá para cruzar qualquer variável e selecionar exatamente os casos de interesse.

O programa não corrige erros de digitação nem faz análises ou gráficos. Quando um valor não está no dicionário, ele fica na planilha como veio, pintado de amarelo, e entra numa lista à parte para conferência. Nada é inventado.

2. Antes de começar

O que é preciso

  • Um computador com Windows e o navegador Google Chrome ou Microsoft Edge.
  • O arquivo do programa, decodificador-sinan-{{versao}}.zip, baixado da página do projeto no GitHub ou do Zenodo (endereços na capa).
  • Não é preciso instalar nada. Depois de baixado, o programa funciona sem internet.

Que tipo de arquivo o programa lê

  • DBC: o formato dos arquivos públicos do DATASUS. É o caso mais comum, e a seção 3 mostra como baixar.
  • DBF: o formato da exportação feita no próprio SINAN.
  • CSV: arquivo de texto separado por vírgula ou ponto e vírgula, com os nomes de coluna do SINAN.

3. Como baixar o arquivo do DATASUS

Os arquivos públicos do SINAN ficam na página de transferência de arquivos do DATASUS: datasus.saude.gov.br/transferencia-de-arquivos. Os arquivos públicos não trazem o nome das pessoas, mas continuam sendo dados de saúde e merecem cuidado.

  1. No campo Fonte, clique em SINAN - Sistema de Informação de Agravos de Notificação.
  2. No campo Modalidade, clique em Dados.
  3. No campo Tipo de Arquivo, clique no agravo. A lista usa a sigla e o nome, por exemplo DENG - Dengue.
  4. No campo Ano, clique no ano. Para escolher vários anos, segure a tecla Ctrl enquanto clica.
  5. No campo UF, clique em BR. Os arquivos do SINAN são nacionais; para ficar só com um estado, use o filtro do programa (seção 5, passo 3.1).
  6. Clique em Enviar.
  1. Aparece a lista de arquivos encontrados, já marcados. Clique em Download.
  2. O site junta os arquivos marcados num arquivo compactado e mostra o link arquivo.zip. Clique nele para baixar.
  3. Na pasta Downloads, clique com o botão direito em arquivo.zip e escolha Extrair tudo. Dentro dele está o arquivo do agravo, por exemplo DENGBR24.dbc. É esse arquivo que vai para o programa.
Como ler o nome do arquivo. DENGBR24.dbc quer dizer: dengue (DENG), Brasil (BR), ano de 2024 (24).
Dados finais e preliminares. A coluna Modalidade da lista diz se os dados do ano são finais ou preliminares. Os preliminares, em geral dos anos mais recentes, ainda podem mudar.

4. Como abrir o programa

  1. Clique com o botão direito em decodificador-sinan-{{versao}}.zip e escolha Extrair tudo.
  2. Abra a pasta decodificador-sinan que foi criada.
  3. Dê dois cliques em index.html. O programa abre no navegador.

Se ele abrir num navegador que não seja o Chrome ou o Edge, clique com o botão direito em index.html, escolha Abrir com e depois Google Chrome ou Microsoft Edge.

A pasta também tem o arquivo LEIA-ME.txt, com um resumo deste guia, o arquivo LICENSE, com a licença, e a pasta exemplos, com arquivos fictícios de dengue para treinar.

Tema escuro ou claro. A tela abre com fundo escuro. O botão Tema claro, no canto de cima, troca para fundo claro, e o mesmo botão (que passa a se chamar Tema escuro) volta ao escuro. O navegador lembra a escolha para a próxima vez. Isso muda só as cores, e nada no resultado.

Para que serve esta ferramenta. Clique nesse título para abrir um texto curto que explica por que os arquivos do DATASUS vêm em códigos, qual é a diferença entre esses arquivos e as tabelas do TABNET, e o que o programa faz. Clique de novo para fechar.

5. Como usar o programa

A tela tem três blocos numerados: 1 Agravo, 2 Arquivo e 3 Opções. Basta seguir na ordem.

Passo 1. Escolha o agravo

Primeiro aparecem só os grupos de agravos (arboviroses, HIV, sífilis e assim por diante). O número ao lado de cada grupo diz quantos agravos ele tem. Clique no grupo, e os agravos dele aparecem logo abaixo. Depois, clique no agravo do arquivo, e o botão escolhido fica azul. Só um grupo fica aberto por vez. O grupo do agravo escolhido fica com a borda azul, mesmo quando outro grupo está aberto.

A dengue já vem escolhida quando o programa abre. Embaixo aparece Agravo escolhido, com o nome do agravo, e qual dicionário será usado, de que documento ele veio e quando foi conferido.

Se você trocar de agravo depois de escolher o arquivo, o programa lê o arquivo de novo com o agravo novo.

Passo 2. Escolha o arquivo

Arraste o arquivo para a área tracejada ou clique em Escolher arquivo. O programa lê o arquivo e mostra, numa faixa verde, quantas notificações e colunas ele tem. Se alguma coluna do arquivo não estiver no dicionário, ela aparece listada ali e vai para a planilha como veio, sem tradução. Também aparecem as colunas do dicionário que não existem naquele arquivo, quando houver.

Acentos trocados. Se os acentos aparecerem errados, abra Acentos aparecendo errado? e escolha outra codificação. Na maioria dos casos, a opção automática acerta.

Arquivo de outro agravo. O programa confere se o arquivo é mesmo do agravo escolhido. Ele olha as colunas e o código do agravo gravado nas notificações (por exemplo, A90 na dengue). Se não for, ele não gera planilha e explica o motivo. Quando reconhece de que agravo o arquivo parece ser, mostra um botão, por exemplo Usar Dengue. Clique nele para ler o arquivo de novo com esse agravo. O programa nunca troca de agravo sozinho.

Passo 3. Ajuste as opções

O bloco de opções aparece depois que o arquivo é lido. As opções já vêm prontas para o uso mais comum, e todas são opcionais. A figura mostra o bloco com os valores de quando ele aparece.

3.1 Filtrar registros

Os filtros deixam na planilha só parte das notificações. São três filtros, e dá para usar um, dois ou os três ao mesmo tempo. Quando há mais de um, a notificação precisa passar por todos para entrar na planilha. Sem filtro, entram todas as notificações do arquivo.

Em cada linha, a primeira lista escolhe qual coluna do arquivo o filtro usa. Isso importa porque a ficha tem, por exemplo, a UF de notificação e a UF de residência, que nem sempre são iguais. As listas só mostram as colunas daquele tipo que existem no arquivo.

FiltroComo funciona
UFNa primeira lista, escolha a coluna de UF. Na dengue, por exemplo, há a UF de notificação, de residência, de hospitalização e a provável de infecção. Na segunda lista, escolha a UF. Cada UF aparece com o número de notificações que ela tem no arquivo, contadas na coluna escolhida. Um código de UF que não existe na tabela do IBGE aparece como "Código ... (sem tradução)".
MunicípioSó funciona depois de escolher uma UF. Na primeira lista, escolha a coluna de município (de notificação, de residência etc.). Na segunda, escolha o município entre os municípios da UF escolhida. Atenção: o filtro de UF e o de município podem usar colunas diferentes. Por exemplo, dá para pedir as notificações feitas numa UF de pacientes residentes num município. Confira se é isso que você quer.
PeríodoNa primeira lista, escolha qual data usar: data da notificação, dos primeiros sintomas, da investigação, do óbito, do encerramento, da digitação e todas as outras datas da ficha que existirem no arquivo. Embaixo, o programa mostra a primeira e a última data dessa coluna no arquivo. Preencha de, até ou os dois. Só "de" pega daquela data em diante, e só "até" pega até aquela data. As duas datas entram no período. Com o filtro de período, as notificações com essa data em branco ou impossível (como 30/02) ficam de fora.

O filtro escolhido fica registrado na aba Resumo da planilha. Assim, dá para saber depois quais notificações entraram.

3.2 Colunas

Estas opções definem o formato e a quantidade de colunas da planilha.

  • Manter também a coluna com o código original, ao lado da traduzida (desmarcada no início): marque para que cada coluna traduzida venha acompanhada de uma coluna com o código como veio no arquivo, com o nome usado no SINAN (por exemplo, Sexo e, ao lado, CS_SEXO). Ajuda a conferir a tradução e a comparar com outras bases.
  • Incluir o nome original da coluna numa segunda linha de cabeçalho (desmarcada no início): a primeira linha traz o nome legível, e a segunda, o nome do SINAN (por exemplo, "Data da notificação" e, embaixo, DT_NOTIFIC). Fica desligada quando o formato para análise está marcado.
  • Formato para análise (R, Stata, Python) (desmarcada no início): veja a seção 8.
  • Escolher quais colunas incluir: clique nesse título para abrir a lista de todas as colunas que podem ir para a planilha. Entre parênteses aparece quantas estão marcadas. Cada coluna mostra o nome legível e, entre parênteses, o nome do SINAN. As colunas que o arquivo traz mas o dicionário não tem aparecem como "(sem tradução)". As colunas extras, calculadas pelo programa, aparecem como "(coluna extra)". São, por exemplo, a região e a macrorregião de saúde, a semana epidemiológica calculada e os avisos de possível erro de notificação. Desmarque o que não precisar. Os botões Marcar todas e Desmarcar todas ajudam quando você quer só algumas colunas: desmarque todas e marque as que interessam. É preciso deixar pelo menos uma marcada.
Dica para escolher variáveis. A lista de colunas é um bom lugar para conhecer o que a ficha do agravo traz. Para uma análise sobre sexo, raça/cor e evolução, por exemplo, desmarque todas, marque só essas colunas (e as de data e local que for usar) e gere uma planilha bem menor e mais rápida de abrir.

3.3 Formato da saída

  • Planilha Excel (.xlsx): uma planilha com as abas Dados, Inconsistências, Dicionário usado e Resumo (seção 6).
  • CSV: um arquivo de texto com os dados, para arquivos muito grandes. Vem com ponto e vírgula entre as colunas e datas em dd/mm/aaaa, e abre direto no Excel em português. As abas de apoio (Inconsistências, Dicionário usado e Resumo) vêm num segundo arquivo, do Excel, com o mesmo nome terminado em _apoio.

Embaixo, o programa mostra quantas notificações vão para a planilha. Com o filtro de UF, o número é exato. Com os filtros de município ou período, ele mostra o máximo possível, porque o número exato só se sabe no processamento. Acima de 300 mil notificações, ele avisa que a planilha do Excel fica pesada. Acima do limite do Excel (1.048.576 linhas), a opção Excel fica bloqueada e o CSV é escolhido sozinho.

Passo 4. Processe e baixe a planilha

O botão Processar e baixar a planilha fica numa barra fixa no pé da tela, sempre à vista enquanto você ajusta as opções. Não é preciso rolar a lista de colunas até o fim para achá-lo. A barra também lembra o nome do arquivo, o agravo e quantas colunas estão marcadas.

Clique no botão. Uma barra mostra o andamento. O botão Cancelar interrompe o processamento e volta para as opções. Um arquivo nacional de um ano pode levar alguns minutos, e a tela não trava enquanto isso.

No fim aparece Pronto!, com o número de notificações lidas, quantas foram para a planilha e quantos valores ficaram sem tradução. A planilha vai sozinha para a pasta Downloads do navegador, com o nome do agravo e a data, por exemplo dengue_decodificado_2026-11-21.xlsx. Se o download não começar, use o botão azul.

Para gerar outra planilha do mesmo arquivo com outras opções (outro filtro ou outras colunas, por exemplo), clique em Mudar opções e processar de novo.

6. Como entender a planilha

A planilha tem quatro abas: Dados, Inconsistências, Dicionário usado e Resumo. As figuras desta seção foram montadas a partir da planilha gerada com o arquivo fictício, mostrando só algumas linhas e colunas.

Aba Dados

Cada linha é uma notificação. Cada coluna tem o nome legível no cabeçalho. Datas saem como datas do Excel, e a idade sai com a unidade, como "85 anos". Quando a opção Manter também a coluna com o código original está marcada, como no exemplo deste guia, a coluna traduzida vem seguida da coluna com o código original, que leva o nome usado no SINAN (por exemplo, Sexo e, ao lado, CS_SEXO).

Amarelo quer dizer "confira". O valor foi mantido como veio no arquivo e não foi traduzido. Pode ser um código que não existe no dicionário, uma data impossível ou uma idade fora do razoável (acima de 23 horas, 29 dias, 11 meses ou 110 anos). Quando a ficha mostra que o campo não comporta aquele código, a célula sai como "Inconsistência/Não Preenchido" (ou "Inconsistência/Preenchido erroneamente"), também em amarelo, e o código original fica na coluna do código, se ela estiver marcada.

Colunas extras. Alguns agravos ganham colunas calculadas pelo programa, ao lado da coluna de onde vieram. Elas trazem a região e a macrorregião de saúde, a semana epidemiológica calculada da data ou um aviso de possível erro de notificação (por exemplo, nas toxoplasmoses, o CID B58 numa gestante). O dado original nunca é alterado.

Em branco não é o mesmo que "Ignorado". "Ignorado" é uma resposta do dicionário: quem preencheu a ficha marcou que a informação não era conhecida. Campo em branco é campo que não foi preenchido, e o programa deixa em branco. Na análise, decida você se "Ignorado" conta como dado faltante.

Aba Inconsistências

Lista cada valor que ficou sem tradução, com a coluna, o valor encontrado, o motivo e quantas vezes ele aparece. É por aqui que se começa a conferência.

Aba Dicionário usado

Diz qual agravo e qual versão do dicionário foram aplicados, quem conferiu e quando, quais documentos oficiais foram usados e, mais abaixo, todas as categorias de cada coluna. Com essa aba, qualquer pessoa consegue verificar de onde saiu cada tradução.

Aba Resumo

Registra o arquivo de entrada, o número de notificações, os filtros aplicados, as opções escolhidas, a data e hora do processamento e a versão do programa. Vale guardar junto com a análise.

7. Situações comuns

O arquivo é grande demais para o Excel.

O Excel aceita no máximo 1.048.576 linhas. O arquivo nacional de um ano inteiro de dengue costuma passar disso. Use os filtros de UF, município ou período, ou escolha a saída em CSV. No CSV, as abas de apoio (Inconsistências, Dicionário usado e Resumo) vêm num arquivo do Excel separado.

A planilha demora para abrir.

Acima de cerca de 300 mil notificações, a planilha do Excel fica pesada e pode levar vários minutos para abrir. O programa avisa quando for o caso. Filtrar ou usar CSV resolve.

Apareceu "O arquivo não parece ser de...".

O arquivo é de outro agravo ou não é um arquivo do SINAN. Confira o agravo escolhido no passo 1 e a sigla no nome do arquivo (tabela da seção 2). Se aparecer um botão como Usar Dengue, o programa reconheceu o agravo provável: clique nele para ler o arquivo com esse agravo.

Os acentos aparecem trocados.

No passo 2, abra Acentos aparecendo errado? e escolha outra codificação. Arquivos de sistemas antigos costumam usar Windows-1252.

A página abre em branco.

Use o Chrome ou o Edge atualizados. Confira se o arquivo .zip do programa foi extraído antes de abrir o index.html.

O download da planilha não começou.

Clique no botão azul Baixar que aparece no fim do processamento. Se o navegador perguntar se pode baixar, permita.

A planilha veio sem as notificações que eu esperava.

Confira os filtros (passo 3.1) e a aba Resumo, que registra os filtros usados. Lembre que o filtro de período deixa de fora as notificações com a data escolhida em branco, e que os filtros de UF e de município podem estar usando colunas diferentes (notificação ou residência, por exemplo).

Não acho o botão de processar.

Ele aparece na barra fixa no pé da tela depois que o arquivo é lido. Se a barra não aparece, escolha o arquivo no passo 2.

Muitas células amarelas numa mesma coluna.

Veja a aba Inconsistências. Se o mesmo código aparece muitas vezes, pode ser um código novo que o dicionário oficial ainda não tem, ou um arquivo de período diferente do previsto no dicionário. O valor original nunca é perdido.

8. Para usar no R, Stata ou Python

Marque Formato para análise (R, Stata, Python) antes de processar. Com essa opção:

  • as colunas usam o nome do SINAN em minúsculas (cs_sexo, dt_notific), e o código original fica em <nome>_cod (cs_sexo_cod);
  • a coluna idade_anos traz a idade em anos completos, como número (menor de 1 ano vale 0; idade inválida ou implausível fica vazia);
  • o cabeçalho tem uma linha só;
  • no CSV, o separador é a vírgula, o decimal é o ponto, as datas vêm como aaaa-mm-dd e o texto vem em UTF-8.

O texto das categorias é o mesmo da planilha comum. O nome legível de cada coluna continua na aba Dicionário usado.

No R, peça para o leitor olhar todas as linhas antes de decidir o tipo de cada coluna. Sem isso, uma coluna de data vazia nas primeiras mil linhas pode ser lida como vazia inteira:

dados <- readxl::read_excel("arquivo.xlsx", sheet = "Dados", guess_max = 1048576)
dados <- readr::read_csv("arquivo.csv", guess_max = Inf)
